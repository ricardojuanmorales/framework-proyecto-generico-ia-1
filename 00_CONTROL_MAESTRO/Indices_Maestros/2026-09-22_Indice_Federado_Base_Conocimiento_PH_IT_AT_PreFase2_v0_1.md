# Índice Federado de Base de Conocimiento PH-IT-AT · Pre-Fase 2 v0.1

**Fecha:** 2026-09-22
**Estado:** candidato estructural
**Función:** navegación e invocación lógica, no propiedad temática

## 1. Tesis

La Base Común no necesita una carpeta central que contenga copias de conocimiento transversal.

```text
Base Común = red federada de fuentes canónicas
```

Este índice registra **dónde vive** cada clase de conocimiento y **cómo se invoca**.

## 3. Propiedad y residencia

```text
residencia documental != propiedad epistemológica
```

El índice debe registrar ambas dimensiones por separado cuando sea material.

## 4. Conocimiento específico

Conocimiento inequívocamente específico puede residir bajo el perfil correspondiente.

El conocimiento común no se duplica dentro de cada perfil.

## 5. Caleidoscopio

No se usa como depósito de Base Común.

Se indexan desde allí solo artefactos cuyo sujeto sea emergencia o recombinación caleidoscópica.

## 6. F2-BCC histórica

Los objetos históricos F2-BCC se consideran:

- antecedentes;
- hipótesis de organización;
- inventario reutilizable;
- deuda de residencia a revisar.

No se promueven automáticamente a arquitectura activa Pre-Fase 2.

## 7. Evolución del índice

Este índice debe crecer por referencia a fuentes ya justificadas por uso, no por anticipación exhaustiva.
