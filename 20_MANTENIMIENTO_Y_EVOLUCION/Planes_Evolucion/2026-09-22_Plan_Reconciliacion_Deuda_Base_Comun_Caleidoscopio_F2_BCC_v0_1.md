# Plan de reconciliación de deuda estructural · Base Común / Caleidoscopio / F2-BCC v0.1

**Fecha:** 2026-09-22
**Estado:** candidato de evolución estructural
**Rama:** integracion-ph-bases-fase2

## 1. Propósito

Resolver deuda histórica sin borrar trazabilidad ni ejecutar migraciones masivas prematuras.

## 2. Regla de intervención

```text
clasificar
→ identificar fuente canónica futura
→ crear referencia lógica
→ verificar
→ reubicar o deprecar cuando proceda
→ preservar historia
```

No se mueve un archivo solo porque su ruta actual sea imperfecta.

## 3. Caleidoscopio

### Estado actual
Contiene un mapa de Base de Conocimiento Común.

### Estado objetivo
Caleidoscopio contiene únicamente objetos cuyo sujeto sea la emergencia y recombinación caleidoscópica.

### Acción
- preservar por ahora el mapa histórico;
- marcarlo como antecedente, no propietario de Base Común;
- redirigir su función de navegación al Índice Federado Pre-Fase 2;
- decidir migración física solo después de pagar referencias.

## 4. F2-BCC histórica bajo PH

### Estado actual
Documentos comunes y de Fase 2 residen históricamente bajo PH.

### Estado objetivo
Cada objeto se clasifica como:

- específico PH;
- común federado;
- metodológico;
- gobernanza;
- evaluación;
- seguridad;
- histórico/deprecado.

### Acción
No mover en bloque.

Aplicar revisión por uso e invocabilidad durante Fase 2 progresiva.

## 5. Glosarios

### Estado actual
- Glosario Centralizado v0.2.
- Glosario Común Mínimo experimental.

### Estado objetivo
Una sola línea evolutiva del Glosario Centralizado.

### Acción
- v0.3 reconciliado pasa a candidato activo;
- glosario mínimo queda como evidencia de proceso;
- no mantener dos glosarios rectores.

## 6. Mapa mínimo de Bases experimental

El documento experimental de B4 deja de ser candidato arquitectónico directo.

Sus funciones se separan en:

- **método de crecimiento** → 03;
- **índice federado** → 00;
- **taxonomía común** → 05/Taxonomias;
- **conocimiento sustantivo** → rutas semánticas 03–21.

## 7. Delta PH robustecido

Permanece como vehículo transicional.

Después de autorización H3:

- integrar SDD mediante referencia metodológica;
- integrar reversibilidad en gobernanza PH;
- integrar documentación operacional en C07;
- integrar lenguaje de autoridad donde corresponda;
- verificar coherencia;
- retirar delta de arquitectura activa y conservarlo como trazabilidad.

## 8. Criterios de migración física

Mover un objeto solo si se cumplen:

1. residencia objetivo inequívoca;
2. referencias conocidas;
3. fuente canónica decidida;
4. ausencia de duplicación editable;
5. enlaces críticos pagados;
6. reversibilidad documentada.

## 9. Qué no hacer

- no crear una nueva macrocarpeta Base_Comun;
- no convertir 00 en biblioteca sustantiva;
- no borrar Caleidoscopio;
- no mover toda F2-BCC de una vez;
- no crear copias para “facilitar” transición;
- no activar Fase 2 por el solo hecho de reconciliar estructura.

## 10. Estado esperado

```text
deuda visible
+ rutas objetivo claras
+ migración progresiva
+ historia preservada
```
