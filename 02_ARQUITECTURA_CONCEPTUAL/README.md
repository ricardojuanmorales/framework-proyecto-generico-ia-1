# 02_ARQUITECTURA_CONCEPTUAL

**Estado:** activo · Framework Genérico V5.1.0.

Este cartapacio conserva y hace evolucionar la **arquitectura conceptual del Framework**: sus relaciones fundamentales, lentes transversales, mapas, modelos de integración, Caleidoscopio y referencias canónicas.

## Referencia canónica integrada vigente

- `Arquitecturas_Referencia/2026-10-08_Arquitectura_Conceptual_Integrada_Framework_Canon_v1_0.md`

Esta referencia integra y amplía el estado conceptual previo. Define, entre otros elementos:

- el Framework como sistema sociotécnico-transdisciplinario evolutivo;
- el problema situado como centro;
- PH, IT y AT como lentes y capacidades;
- el Marco Teórico Longitudinal y su relación con el Marco Pedagógico;
- la ecología del conocimiento común, especializado y federado;
- la macroestructura 00–21 + 99 como cuerpo operativo y memoria evolutiva;
- el Portafolio como memoria situada del participante;
- el Caleidoscopio como posible propiedad emergente;
- la transferencia simétrica reversible;
- Estudios Generales como raíz y laboratorio académico;
- y el canon como verdad vigente, versionada, trazable y revisable.

## Principio de verdad

> **Canon no significa eternidad. Significa referencia vigente, explícita, trazable y revisable.**

El cartapacio 02 debe permitir reconstruir no solo qué arquitectura está vigente, sino también cómo llegó a serlo y qué tensiones podrían transformarla en una versión futura.
