# Arquitectura de Integración Pedagógica, Conocimiento Común, Comunidad y Caleidoscopio V5 v1.0

**Fecha:** 2026-10-05  
**Estado:** APROBADO · canónico  
**Versión objetivo:** Framework Genérico V5.0.0  
**Decisión humana:** aprobada en sesión de integración A-G.

## 1. Tesis arquitectónica

El Framework es un sistema sociotécnico-transdisciplinario evolutivo. La aplicación es una superficie operativa, no el Framework completo.

```text
PERFIL = lente
FRAMEWORK = espacio operativo
PROBLEMA = centro
```

La integración aprobada articula cinco elementos:

1. Base de Conocimiento común;
2. PH · IT · AT;
3. Marco Pedagógico transversal;
4. comunidad de aprendizaje/práctica;
5. Caleidoscopio como propiedad emergente.

## 2. Base de Conocimiento común

Se define como bien epistemológico compartido del ecosistema. Conserva o referencia fuentes, bibliografía, anotaciones, conceptos, procedencia, validación, relaciones, usos e historial.

Principio:

```text
una base común
→ múltiples lentes de acceso
→ trazabilidad compartida
```

No pertenece a PH, IT ni AT.

## 3. Perfiles PH · IT · AT

Los perfiles son lentes operativas y epistemológicas que acceden al mismo patrimonio común.

- PH enfatiza diseño, tecnología, construcción, seguridad, continuidad y gobernabilidad.
- IT enfatiza preguntas, método, evidencia, procedencia, incertidumbre y validez.
- AT enfatiza percepción, experiencia, simbolismo, representación, imaginación y transformación situada.

La fuente puede ser común; la pregunta, lectura e interpretación dependen de la lente y el contexto.

## 4. Marco Pedagógico

El Marco Pedagógico es una **capa transversal de gobernanza pedagógica** del ecosistema.

No queda subordinado a APRENDER ni al app. Orienta incorporación, participación, mediación H/M/IA, producción y contraste de conocimiento, reflexión, memoria, transferencia, comunidad y evolución.

## 5. Comunidad

La comunidad es dimensión constitutiva del Framework. Puede aprender, contribuir y participar en la evolución gobernada del repertorio común.

La comunidad no adquiere autoridad canónica automática. Sus aportaciones deben conservar procedencia y atravesar revisión proporcional.

## 6. Caleidoscopio

El Caleidoscopio no es un cuarto perfil ni un módulo. Es una propiedad emergente posible de una recombinación situada, significativa y trazable de dos o más lentes o formas de conocimiento.

```text
PH + IT + AT != Caleidoscopio automático
```

## 7. Flujo sistémico

```text
problema real
→ participación situada
↔ PH · IT · AT
↔ Base de Conocimiento común
↔ Humano · Máquina · IA
↔ Marco Pedagógico transversal
→ práctica + evidencia + memoria + reflexión
→ transferencia + evolución
→ posible emergencia caleidoscópica
↺ retroalimentación al ecosistema
```

## 8. Autoridad y responsabilidad

```text
Framework propone y estructura
IA analiza, contrasta y sintetiza
Máquina ejecuta, persiste y evidencia
Comunidad contribuye y delibera
Humanos validan, autorizan y asumen responsabilidad material
```

## 9. Relación con memoria

- **Base de Conocimiento común:** patrimonio epistemológico disponible.
- **Conocimientos activos:** conocimiento invocado en el trabajo presente.
- **PORTAFOLIO:** historia de uso, interpretación, decisión, cambio y reapertura.

```text
corregir != borrar
revisar != reescribir el pasado
```

## 10. Ciclo de evolución

```text
uso real
→ evidencia
→ tensión o hallazgo
→ contraste bibliográfico
→ propuesta
→ revisión pertinente
→ gate humano
→ nueva versión
```

La evolución responde a evidencia; no a novedad teórica o tecnológica por sí sola.

## 11. Deuda aceptada

Esta arquitectura no declara validadas empíricamente la efectividad pedagógica, la existencia de una comunidad de práctica madura ni la emergencia caleidoscópica. Esas validaciones requieren uso real.

## 12. Gate

Este documento constituye la referencia arquitectónica para el pago de deuda asociado a conocimiento común, pedagogía, comunidad e integración caleidoscópica.
