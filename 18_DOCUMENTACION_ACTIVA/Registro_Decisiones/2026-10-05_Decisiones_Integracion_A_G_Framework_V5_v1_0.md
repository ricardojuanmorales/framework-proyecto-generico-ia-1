# Registro de decisiones A-G · Integración pedagógica y conocimiento común V5

**Fecha:** 2026-10-05  
**Estado:** APROBADO  
**Ámbito:** arquitectura, pedagogía, conocimiento, perfiles, comunidad, Caleidoscopio y deuda.

## Decisiones

### A. Arquitectura de integración
Aprobada. Base de Conocimiento común, PH·IT·AT, Marco Pedagógico, comunidad y Caleidoscopio se integran como relaciones del ecosistema.

### B. Marco Pedagógico
Aprobado como capa transversal de gobernanza pedagógica. El principio 3 queda fijado como capacidad colectiva creciente con autonomía y responsabilidad humanas preservadas.

### C. Base de Conocimiento común
Aprobada como bien epistemológico compartido. Una base común; múltiples lentes de acceso. Se distinguen fuente/evidencia, interpretación, decisión y canon.

### D. Invocación PH·IT·AT
Aprobada. Cada perfil accede al mismo patrimonio desde preguntas y responsabilidades distintas. No se crean bibliotecas por perfil.

### E. Comunidad y gobernanza
Aprobada. La comunidad puede aprender, contribuir y ayudar a evolucionar. Aporte comunitario no equivale automáticamente a validación ni canon.

### F. Verificación caleidoscópica
Aprobada. Cinco condiciones mínimas: situación real, pluralidad de lentes, contraste real, emergencia nueva y trazabilidad. Estados: candidata, reconocida, validada, transferida.

### G. Deuda y pago
Aprobado el registro explícito de deuda. Se prioriza saldar deuda arquitectónica, documental, técnica y metodológica antes del uso real, dejando pendiente solo la que requiere evidencia empírica.

## Regla de autoridad

```text
Framework propone / IA analiza y contrasta / Máquina ejecuta y evidencia / Humano decide y autoriza
```

## Gate

Este registro autoriza el plan expedito de pago de deuda previo al uso real controlado.
