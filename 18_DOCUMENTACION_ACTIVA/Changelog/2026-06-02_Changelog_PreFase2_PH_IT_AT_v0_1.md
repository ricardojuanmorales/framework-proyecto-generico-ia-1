## 2. Cambios principales

| Cambio | Descripción | Estado |
|---|---|---|
| Lógica espiral de fases | Las Fases 1-6 se reinterpretan como progresión común PH-IT-AT | Incorporado |
| Fase 2 como base común | La Fase 2 será base de conocimiento para unidades, metodologías, destrezas, guías, protocolos, prompts y herramientas | Incorporado |
| N1-N4 como madurez operativa | Los niveles se aplican a los tres perfiles | Incorporado |
| Problema común como centro | Los proyectos caleidoscópicos parten del problema, no del perfil | Incorporado |
| Tríada sin centro fijo | PH, IT y AT se declaran equivalentes | Incorporado |
| Lente latente | En activaciones duales, el tercer perfil queda presente con sugerencias | Incorporado |
| Curaduría transdisciplinaria | Se adopta como mecanismo de integración | Incorporado |
| Tres capas de nivelación | Usuario, proyecto y producto se miden por separado | Incorporado |
| Corrección de ubicación documental | El mapa de ruta va en `03_METODOLOGIA_Y_FLUJO_DE_TRABAJO/Secuencias_Fase_Por_Fase/` | Incorporado |
| Respeto a estructura auditada | No crear rutas nuevas no aprobadas | Incorporado |
