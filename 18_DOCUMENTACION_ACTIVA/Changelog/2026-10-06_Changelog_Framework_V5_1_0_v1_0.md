# Changelog · Framework Genérico V5.1.0

**Fecha:** 2026-10-06  
**Estado:** candidato de release

## Added

- Marco Pedagógico V5 v1.1 como gobernanza transversal;
- Base de Conocimiento común;
- corpus bibliográfico inicial y verificación separada de fuentes;
- invocación estructurada PH·IT·AT;
- gobernanza comunitaria mínima;
- verificación cualitativa de emergencia caleidoscópica;
- arquitectura de distribución Framework ↔ repositorios ↔ paquete ↔ app;
- macroestructura 00–21 + 99 con materialización proporcional;
- núcleo Integral Autosostenido V5.1.0.

## Changed

- la aplicación se consolida como superficie operativa de referencia para START, INTEGRATE y AUDIT;
- Base Federada se entiende como mecanismo de acceso, mientras la Base de Conocimiento común es el patrimonio epistemológico;
- la transferencia simétrica reversible pasa a formar parte explícita del circuito de evolución;
- documentación humana y README se sincronizan con la arquitectura vigente;
- nuevos proyectos se identifican como Framework 5.1.0.

## Compatibility

- proyectos y paquetes V5.0.0 continúan siendo importables;
- schemas de proyecto permanecen en 0.1.0;
- package portable permanece en 0.1.0;
- no se fuerza migración de proyectos V4.1 existentes.

## Preserved

- local-first;
- ausencia de backend obligatorio;
- autoridad humana;
- V4 histórica;
- reversibilidad;
- releases anteriores inmutables.

## Debt kept open

- validación con lector de pantalla;
- verificación primaria completa del corpus bibliográfico;
- validación pedagógica empírica;
- comunidad de práctica efectiva;
- evidencia real de emergencia caleidoscópica y transferencia de aprendizaje.
