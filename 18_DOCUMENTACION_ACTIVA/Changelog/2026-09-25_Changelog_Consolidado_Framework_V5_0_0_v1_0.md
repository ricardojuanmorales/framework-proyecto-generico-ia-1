# Changelog consolidado · Framework Genérico V5.0.0

**Fecha:** 2026-09-25  
**Estado:** canónico post-release

## Added

- aplicación V5 local-first;
- APRENDER progresivo;
- modos START / INTEGRATE / AUDIT;
- Estado vivo;
- PORTAFOLIO operativo;
- Base Federada;
- Conocimientos activos;
- correcciones trazables;
- supersesión de decisiones;
- transferencias editables;
- exportación ZIP / JSON;
- importación segura;
- roundtrip semántico;
- schemas ejecutables;
- CI Verify / Harden / Pages;
- GitHub Release reproducible;
- ZIP oficial + checksum SHA-256;
- accesos públicos en README.

## Changed

- transición de V4 document-centric a V5 como ecosistema operativo evolutivo;
- PH, IT y AT pasan a operar como lentes integradas dentro de V5;
- Caleidoscopio queda estabilizado como propiedad emergente, no cuarto perfil;
- autoridad humano · máquina · IA queda explícita;
- README pasa a funcionar como puerta de entrada operativa;
- GitHub Pages pasa a ser gobernado mediante GitHub Actions;
- granularidad de trabajo se reduce en etapa post-release.

## Fixed

- APRENDER insuficientemente guiado;
- ausencia de superficie humana PORTAFOLIO;
- falta de observabilidad en invocación de conocimiento;
- falta de gestión visible de Conocimientos activos;
- feedback insuficiente ante importaciones inválidas;
- inconsistencia de identidad entre `0.1.0`, `5.0.0-dev`, RC y versión estable;
- ausencia de Release oficial descargable.

## Preserved

- V4 histórica accesible;
- procedencia y memoria documental;
- schemas con versionado independiente;
- autoridad humana final;
- posibilidad de reapertura.
