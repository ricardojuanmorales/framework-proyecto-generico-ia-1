# Bitácora Fase 2 · Modelo Portable de Proyecto V5 v0.1

**Fecha:** 2026-09-22
**Estado:** candidato en rama Fase 2

## Decisión

La aplicación V5 no será repositorio obligatorio ni dependencia permanente.

El proyecto debe poder:

```text
salir de la app
→ vivir en GitHub o filesystem
→ continuar
→ reimportarse
→ transferir aprendizaje
```

## Transferencia desde AI StoryLab

Se transfieren capacidades, no carpetas:

- manifest;
- schemas;
- preservación de origen;
- roundtrip;
- continuidad;
- portafolio;
- versionado.

## Schemas

Se limita el núcleo inicial a cinco contratos conceptuales:

- project;
- framework-state;
- portfolio;
- decision;
- transfer.

Evidence permanece inicialmente como entrada tipada del portafolio.
