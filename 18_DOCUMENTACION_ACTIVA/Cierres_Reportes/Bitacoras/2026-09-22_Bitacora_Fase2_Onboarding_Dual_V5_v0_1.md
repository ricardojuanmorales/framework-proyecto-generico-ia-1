# Bitácora Fase 2 · Onboarding Dual Usuario + Colaborador V5 v0.1

**Fecha:** 2026-09-22
**Estado:** candidato en rama Fase 2

## Decisión

V5 tendrá dos puertas de entrada explícitas:

```text
usar el Framework
!=
evolucionar el Framework
```

## Usuario

Debe poder:
- aprender;
- activar;
- diseñar;
- exportar;
- continuar.

Sin conocer 00–21 ni Git al principio.

## Colaborador

Debe poder:
- comprender arquitectura;
- trabajar en rama;
- ejecutar/verificar;
- documentar;
- someter PR;
- preservar compatibilidad.

## Simplificación

No se crea una aplicación separada para colaboradores.

La app pública atiende principalmente al usuario.

La contribución se gobierna desde repositorio + documentación + verificación.

Contrato de Release V5 + especificación conceptual del MVP de aplicación.
