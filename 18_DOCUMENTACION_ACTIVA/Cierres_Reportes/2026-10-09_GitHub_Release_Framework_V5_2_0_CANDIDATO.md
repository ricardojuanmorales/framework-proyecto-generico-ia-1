# Framework Genérico v5.2.0 · Notas de release (CANDIDATO)

**Fecha de preparación:** 2026-10-09  
**Estado:** CANDIDATO, NO PUBLICADO. No implica creación de tag, asset o release oficial.

## Motivación histórica

La versión 5.1.0 fue documentada el 2026-10-06. El 2026-10-08 se fijó una Arquitectura Conceptual Integrada con alcance más amplio, ya presente en el repositorio maestro, pero no garantizada dentro de la instantánea estable anterior. v5.2.0 pretende hacer coincidir canon, núcleo autosostenido, aplicación y distribución.

## Arquitectura integrada

- Framework como sistema sociotécnico-transdisciplinario evolutivo; problema situado como centro; PH/IT/AT como lentes no jerárquicos.
- Cinco niveles: fundamento longitudinal, ecología del conocimiento, cuerpo estructural-operativo, implementación situada, emergencia-transferencia-evolución.
- Corpus fundacional de Educación General en cuatro áreas, Marco Teórico Longitudinal y Marco Pedagógico como capa operacional.
- Macroestructura 00–21 + 99 como cuerpo estructural, operativo y memorial.
- Patrimonio común, especialización y conocimiento federado sin homogeneización.
- Portafolio como memoria situada, agencia humana en la relación humano·máquina·IA.
- Caleidoscopio como posible emergencia cualitativa, no cuarto perfil ni síntesis automática.
- Transferencia simétrica reversible y canon versionado y revisable.

## Cambios operativos candidatos

- Aplicación y metadatos npm alineados a 5.2.0.
- Proyectos nuevos identificados como 5.2.0.
- Contratos JSON y ZIP admiten proyectos 5.0.0, 5.1.0 y 5.2.0 sin exigir conversión automática.
- Se conserva versión de esquema y paquete portable 0.1.0.
- Nuevo núcleo integral autosostenido v5.2.0 sin alterar v5.1.0 histórica.
- Nuevas pruebas de regresión JSON/ZIP, pendientes de ejecución por CI.

## Artefactos requeridos para publicación

1. Snapshot del commit exacto aprobado y tag inmutable `v5.2.0`.
2. Archivo fuente reproducible que incluya los dos documentos canónicos del 2026-10-08 y el nuevo núcleo autosostenido.
3. Checksum SHA-256 y verificación cruzada de descarga.
4. Resultado PASS de typecheck, build, tests, auditoría de dependencias, arquitectura, privacidad, accesibilidad y seguridad.
5. Comprobación de enlaces, app publicada y guía de compatibilidad.
6. README general actualizado al final, sobre contenidos efectivamente incluidos.
7. Gate humano explícito antes de publicar.

## Límites

Este release no debe reclamar validación pedagógica empírica general, comunidad de práctica madura o emergencia caleidoscópica generalizada sin evidencia real.

## Preservación histórica

Las versiones v4, v5.0.0 y v5.1.0 no se reescriben. La relación entre ellas se conserva en changelog, registro de auditoría y genealogía de Git.
