# Framework Genérico v5.2.0 · Arquitectura Conceptual Integrada

**Fecha:** 2026-10-09  
**Alcance:** consolidación conceptual, operacional y documental de la versión 5.2.0.

## Novedad histórica

La arquitectura conceptual integrada se canonizó el 8 de octubre de 2026, después del release v5.1.0. Esta versión incorpora esa arquitectura a una nueva instantánea reproducible, preservando releases previos y el historial de evolución.

## Arquitectura incorporada

- Framework como sistema sociotécnico-transdisciplinario evolutivo, con el problema situado como centro.
- PH, IT y AT como lentes no jerárquicos, especializados y activables proporcionalmente.
- Fundamento epistemológico de Educación General de cuatro áreas, Marco Teórico Longitudinal y Marco Pedagógico.
- Distinción entre patrimonio epistemológico común, especialización, base federada y conocimiento situado.
- Macroestructura 00–21 + 99 como cuerpo estructural, operativo y memorial.
- Portafolio como memoria situada de las personas.
- Ecología cognitiva humano · máquina · IA con agencia y responsabilidad humana.
- Caleidoscopio como posible propiedad emergente de la interacción plural, contrastada y trazable; no un cuarto perfil.
- Transferencia simétrica reversible y canon evolutivo, revisable y versionado.

## Aplicación y compatibilidad

- Versión de aplicación y metadatos npm: `5.2.0`.
- Nuevos proyectos: `frameworkVersion 5.2.0`.
- Modelo TypeScript, esquema JSON y manifiesto ZIP admiten `5.0.0`, `5.1.0` y `5.2.0`.
- Versión de esquema de proyecto y paquete portable: `0.1.0`, sin migración estructural obligatoria.
- Pruebas de regresión añadidas para exportación/importación JSON y ZIP y versiones históricas.

El flujo de publicación ejecuta el verificador de la aplicación, comprueba la presencia de los documentos canónicos y del núcleo 5.2.0, construye un archivo fuente ZIP desde el commit exacto del tag y verifica un checksum SHA-256 antes de publicar. ## Preservación y límites

Las versiones v4, v5.0.0 y v5.1.0 permanecen históricas. Esta release no afirma validación pedagógica empírica general, comunidad de práctica consolidada ni emergencia caleidoscópica demostrada en todos los contextos. Las necesidades de validación situada permanecen explícitas.
