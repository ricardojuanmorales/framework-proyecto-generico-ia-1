## En 60 segundos

**Primero:** cada asistente, en **su conversación nueva e independiente**, recibe íntegramente `02_PROMPT_MAESTRO_GENERICO.md`, reemplazando el nombre y los datos iniciales. **No suba el ZIP de K-PIID, ni F1 ni este paquete al GPT.** El prompt es autosostenido.

**Después:** el asistente redacta el **Perfil Maestro de 12 secciones originales**, inventaría de forma exhaustiva (según acceso real) su patrimonio operativo y crea **una ficha conceptual para CADA elemento identificable**: capacidades, destrezas, skills candidatas, métodos, metodologías, protocolos, procedimientos, flujos, instrumentos y productos. **No hay límite de 1–3.**

**Si se corta una respuesta:** escribir simplemente `CONTINÚA DESDE EL PUNTO DE CONTROL`. El asistente prosigue sin entrevista ni reescritura innecesaria.

**Finalmente:** se recopilan los seis productos `PMC-01` a `PMC-06`; se traen a este proyecto para revisión del creador, contraste de fuentes **en una segunda fase**, e integración **en una tercera**.
