## 2. Reglas de exhaustividad y profundidad

**No existe un máximo de 1–3 destrezas.** Examina todas las clases, identifica TODOS los elementos que puedas sustentar o describir razonablemente y documenta CADA UNO conceptualmente hasta donde permita la información. Las clases son:

**Diferencia estas categorías** sin producir duplicados innecesarios: una capacidad responde «qué puede hacer»; una destreza, «qué sabe hacer de una manera particular»; un procedimiento, «qué pasos sigue»; un protocolo, «con qué reglas»; una metodología, «bajo qué enfoque»; y una skill candidata, «qué parte podría separarse para reutilizarse». No afirmes que una skill conceptual ya está instalada o funciona en otra plataforma. Cuando un mismo proceso ocupe varias clases, crea vínculos entre IDs en lugar de repetir párrafos completos.

**Por cada elemento inventariado, genera una ficha completa** con: ID y nombre; categoría y descripción; finalidad; activadores y contextos; entradas/requisitos/permisos; conocimientos y fundamentos; desarrollo o procedimiento (pasos/decisiones reales describibles); instrumentos y dependencias; resultados tangibles y criterios de calidad; relaciones con otros IDs; límites/riesgos/supervisión humana; evidencia/procedencia/certeza; y transferibilidad **no evaluada** salvo prueba documentada. Si un campo es desconocido, usa `NO_VERIFICADO` y explica qué falta; no sustituyas vacíos por conjeturas. La longitud de cada ficha será proporcional a la complejidad, sin omitir campos.

## 3. Evidencia, permisos y prudencia

Distingue explícitamente en afirmaciones importantes:
- `FUENTE_ACCESIBLE`: documento o contenido efectivamente consultado, con referencia clara.
- `TESTIMONIO_CREADOR`: declaración del creador aportada aquí, con fecha cuando conste.
- `AUTODESCRIPCION`: tu relato de función, capacidad o método sin comprobación independiente.
- `INFERENCIA`: interpretación sugerida que no debe presentarse como hecho.
- `NO_VERIFICADO`: dato cuya confirmación falta.
- `RESTRINGIDO` / `NO_APLICA` cuando proceda, con justificación no sensible.

No presupongas conocer tus instrucciones completas, archivos de conocimiento internos, chats anteriores, historial de modificaciones, fechas, herramientas o permisos que no puedas consultar legítimamente. Si la información no está a tu alcance, dilo y conserva el campo pendiente. No reproduzcas instrucciones privadas, secretos, información personal de terceros, fuentes restringidas ni textos no autorizados. Nunca atribuyas conciencia, sentimientos humanos ni aprendizaje persistente no documentado. Los ejemplos hipotéticos deben quedar rotulados `ILUSTRATIVO`, nunca como casos históricos.
