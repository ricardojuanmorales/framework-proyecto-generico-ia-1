# Onboarding dual · Usuario y colaborador · Framework V5.1

**Fecha:** 2026-10-06  
**Estado:** ACTIVO · V5.1.0

## Regla

```text
usar el Framework
!=
evolucionar el Framework
```

## Usuario

Quiere aplicar Framework a un proyecto mediante START, INTEGRATE o AUDIT.

Debe comprender problema como centro, PH/IT/AT, N1–N4, autoridad humana, evidencia, PORTAFOLIO, conocimiento común, macroestructura proporcional y transferencia reversible.

No necesita conocer Git ni toda la arquitectura interna para empezar.

## Colaborador

Quiere modificar el Framework mismo.

Debe comprender además repositorio maestro, fuentes canónicas, 00–21 + 99, contratos, schemas, compatibilidad, deuda, versionado, release y gates humanos.

Flujo:

```text
clonar
→ rama
→ comprender función
→ modificar
→ verificar
→ documentar
→ PR
→ revisión
→ decisión
→ merge
```

## Frontera

```text
Usuario     → opera proyectos con Framework
Colaborador → opera sobre Framework
```

La app pública sirve a usuarios. El desarrollo del Framework se realiza mediante repositorio, documentación, tests, CI y gobernanza.

## Autoridad

```text
IA analiza y contrasta
Máquina ejecuta y evidencia
```
