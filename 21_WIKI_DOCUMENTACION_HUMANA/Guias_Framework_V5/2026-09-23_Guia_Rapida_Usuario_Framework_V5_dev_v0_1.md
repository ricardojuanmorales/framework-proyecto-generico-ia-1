# Guía rápida de usuario · Framework V5 dev

**Estado:** Fase 3 · producto en construcción

## Qué puedes hacer hoy

La aplicación V5 permite:

```text
APRENDER
→ ACTIVAR
→ REGISTRAR
→ INVOCAR
→ EXPORTAR
→ IMPORTAR
```

## Modos

### START
Proyecto nuevo.

### INTEGRATE
Añade una capa Framework a un proyecto existente sin reorganizarlo por fuerza.

### AUDIT
Contrasta un proyecto maduro y preserva su procedencia.

## Estado vivo

Puedes registrar:

- evidencia;
- decisiones humanas;
- transferencias;
- N1–N4;
- reaperturas;
- invocaciones de conocimiento.

## Base Federada

Describe una necesidad en lenguaje natural.

La aplicación devuelve pocos resultados con:

- propósito;
- fuente canónica;
- evidencia esperada.

La recomendación no es obligación.

## Portabilidad

Actualmente existen dos representaciones:

1. un archivo JSON de transporte para roundtrip;
2. una materialización lógica multiarchivo con README, manifest, estado, portafolio, decisiones y transferencias.

El empaquetado físico final todavía está en construcción.

## Privacidad

El MVP es local-first:

- sin cuenta;
- sin backend obligatorio;
- sin IA externa obligatoria;
- sin telemetría por defecto.
