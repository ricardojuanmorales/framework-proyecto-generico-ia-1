# 21_WIKI_DOCUMENTACION_HUMANA

**Estado:** activo · Framework Genérico V5.1.0

Este cartapacio reúne la documentación destinada a personas que quieren usar, comprender, transferir o colaborar con el Framework sin tener que navegar primero toda su arquitectura interna.

## Puertas principales

1. **README del repositorio** → explicación humana del ecosistema completo.
2. **Guía rápida V5** → uso cotidiano de START, INTEGRATE y AUDIT.
3. **Onboarding dual** → diferencia entre usar el Framework y contribuir al Framework.
4. **Documentación especializada** → guías por perfil, transferencia, wiki y continuidad.

## Principio

```text
comprender suficiente para actuar
!=
memorizar el repositorio
```

La documentación humana debe reducir carga cognitiva sin ocultar procedencia, límites ni responsabilidad.
