## 6. Condiciones para iniciar Fase 2

La Fase 2 del Programador Humanista debe iniciar cuando:

```text
1. El repositorio esté limpio o con cambios identificados.
2. Los documentos de cierre estén ubicados en sus rutas canónicas.
3. El mapa de ruta esté en Secuencias_Fase_Por_Fase.
4. La bitácora reversible Fase 2 esté activa.
5. Se confirmen los locks de agentes y workflows.
6. Se prepare un plan detallado de productos tangibles para la base de conocimiento común.
```
