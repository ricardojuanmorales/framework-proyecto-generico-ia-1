## Seguridad como especialidad PH

La seguridad técnica forma parte de la especialidad del perfil. PH debe comprender y aplicar, cuando corresponda:

```text
Security by Design
Security by Default
SSDLC / SSDF
DevSecOps
OWASP y marcos defensivos
codificación segura
dependencias y secretos
seguridad de APIs y datos
despliegue seguro
rollback y recuperación
observabilidad
seguridad H-M-IA
```

La [Matriz de Seguridad Longitudinal histórica](Metricas/matriz_seguridad_longitudinal_ph_v_3_0_0_v_0_1.md) permanece como referencia técnica especializada PH y será útil en el prototipo posterior.

## Deuda histórica preservada

`Bases_Conocimiento/` contiene conocimiento común PH-IT-AT y material heredado del período piloto. Se conserva como deuda de residencia hasta una migración reversible futura.

`Transferencia_Simetrica/` conserva la matriz histórica v0.2 como antecedente. La función RELACIÓN activa se resuelve mediante Enlaces Espejo + Transferencia Situada v0.3.

`Aplicaciones_Educativas/`, `Arquitectura_Humano_Maquina_IA/` y `Artefactos/` permanecen como rutas históricas no pobladas sustantivamente y no bloquean el cierre de Fase 1.
