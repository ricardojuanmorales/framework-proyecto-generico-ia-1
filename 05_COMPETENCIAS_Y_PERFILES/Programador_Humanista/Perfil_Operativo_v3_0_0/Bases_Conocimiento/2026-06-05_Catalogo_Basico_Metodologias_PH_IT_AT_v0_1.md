## 0. Propósito

Este catálogo organiza las metodologías básicas que sostienen la Fase 2 PH-IT-AT y su evolución futura hacia productos, proyectos, usuarios, evidencias, seguridad, documentación humana y activación caleidoscópica.

Su función es servir como mapa inicial de métodos invocables. No reemplaza protocolos detallados ni instrumentos específicos. Identifica qué metodología usar, para qué propósito, con qué perfil, en qué nivel y bajo qué condiciones de seguridad.

---

## 1. Principio rector

```text
Las metodologías no son adornos conceptuales.
Son rutas de acción con propósito, evidencia, límites, seguridad y trazabilidad.
```

Cada metodología debe poder responder:

```text
1. ¿Qué problema ayuda a trabajar?
2. ¿Qué perfil la usa principalmente?
3. ¿Qué productos puede generar?
4. ¿Qué evidencia deja?
5. ¿Qué nivel N1-N4 requiere?
6. ¿Qué riesgos o límites tiene?
7. ¿Cómo se transfiere a otros perfiles?
8. ¿Cómo puede activarse caleidoscópicamente?
```

## 9. Criterios para seleccionar una metodología

Antes de seleccionar una metodología, responder:

```text
1. ¿Cuál es el problema?
2. ¿Qué producto se quiere crear?
3. ¿Qué nivel tiene el usuario?
4. ¿Qué nivel requiere el proyecto?
5. ¿Qué nivel exige el producto?
6. ¿Qué perfil lidera?
7. ¿Qué perfiles deben participar o quedar latentes?
8. ¿Qué evidencia se necesita?
9. ¿Qué riesgos de seguridad existen?
10. ¿Qué documentación debe quedar al final?
```

## 12. Relación con seguridad longitudinal

Toda metodología debe revisar:

| Criterio | Pregunta |
|---|---|
| Datos | ¿La metodología maneja datos personales, institucionales o de investigación? |
| Privacidad | ¿Requiere anonimización o consentimiento? |
| IA | ¿Usa IA como apoyo, co-producción o automatización? |
| Agentes | ¿Prepara agentes, multiagentes o workflows? |
| Evaluación | ¿Afecta calificación, progreso o perfil de usuario? |
| Accesibilidad | ¿Puede aplicarse con andamiaje N1-N4? |
| Gobernanza | ¿Requiere aprobación antes de activarse? |

Regla:

```text
Si la metodología usa IA, datos, evaluación o automatización, clasificar seguridad como requiere_revision hasta validación humana.
```
