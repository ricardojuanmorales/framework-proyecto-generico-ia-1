Este índice maestro v0.4 consolida la actualización de Ronda 2A y Bloque 1. Integra la arquitectura de conocimiento común, el mapa de familias de documentos invocables, el formato estandarizado de invocable maestro y el protocolo de pago de deuda estructural.
