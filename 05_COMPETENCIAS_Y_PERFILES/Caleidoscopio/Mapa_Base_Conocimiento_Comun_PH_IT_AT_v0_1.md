## 1. Propósito

Este documento propone la estructura inicial de la base de conocimiento común PH-IT-AT para Fase 2.

La base común debe servir como repositorio vivo de unidades nucleares, metodologías, destrezas, protocolos, guías, prompts, herramientas y documentos oficiales invocables a necesidad.

No se concibe como tres bibliotecas separadas, sino como una base compartida con secciones especializadas y enlaces reversibles.

## 6. Relación con niveles N1-N4

| Nivel | Tipo de documento predominante |
|---|---|
| N1 | guías introductorias, prompts básicos, fichas simples |
| N2 | plantillas, checklists, flujos asistidos, protocolos básicos |
| N3 | metodologías integradas, matrices de evaluación, automatizaciones parciales |
| N4 | gobernanza, agentes, sistemas integrados, operación y sostenibilidad |
