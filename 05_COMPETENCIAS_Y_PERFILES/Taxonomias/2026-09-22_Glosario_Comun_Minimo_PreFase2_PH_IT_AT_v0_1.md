# Glosario común mínimo Pre-Fase 2 · PH-IT-AT v0.1

**Fecha:** 2026-09-22  
**Estado:** candidato experimental  
**Propósito:** ofrecer vocabulario mínimo compartido para preparar Fase 2 sin uniformar identidades disciplinares.

---

| Término | Definición operativa candidata |
|---|---|
| **Capacidad** | Lo que un perfil puede hacer de manera observable y evaluable desde su responsabilidad propia. |
| **Actuación** | Configuración recurrente de varias capacidades desplegadas en una práctica concreta. |
| **Método invocable** | Procedimiento reusable que organiza cómo ejercer capacidades sin convertirse por sí mismo en identidad de perfil. |
| **Base de Conocimiento** | Conocimiento reusable e invocable que sostiene capacidades o actuaciones mediante criterios, métodos, límites o herramientas conceptuales. |
| **Evidencia** | Huella observable producida por una actuación, prueba o proceso. Su significado depende del contexto y de la lente que la interprete. |
| **Verificación** | Comprobación de una condición contra criterios explícitos. |
| **Interpretación** | Lectura situada del significado o implicación de evidencia, artefactos o resultados. |
| **Decisión** | Selección documentable entre alternativas con consecuencias. |
| **Autorización** | Ejercicio explícito de autoridad que permite una acción, transición o cambio. |
| **Habilitación** | Condición operativa que deja disponible un siguiente paso después de cumplir requisitos aplicables. |
| **Gate** | Compuerta que evalúa condiciones de avance y puede permitir, condicionar, pausar o bloquear. |
| **Reserva** | Condición conocida, no bloqueante, que se conserva con contexto y condición de seguimiento. |
| **Deuda** | Trabajo, riesgo, tensión o condición pendiente que conserva responsabilidad y criterio futuro de tratamiento. |
| **Reapertura** | Retorno gobernado a una decisión previamente estabilizada por nueva evidencia, contexto o contradicción. |
| **Reversibilidad** | Capacidad de modificar, retirar, transferir o reabrir una decisión o configuración sin pérdida material de comprensión, trazabilidad o control. |
| **Transferencia** | Movimiento contextualizado de conocimiento, evidencia, artefactos o criterios entre ámbitos o lentes, preservando origen, transformaciones y límites. |
| **Propiedad epistemológica** | Responsabilidad principal sobre la producción, interpretación o validación de cierto conocimiento desde una lente. |
| **Residencia documental** | Ubicación física o lógica de un artefacto dentro del repositorio. No determina por sí sola su propiedad epistemológica. |
| **Consolidación** | Proceso mediante el cual hallazgos suficientemente sustentados pasan de observación dispersa a aprendizaje reusable y gobernado. |

---

## Reglas de uso

1. Estas definiciones no reemplazan vocabularios especializados PH, IT o AT.
2. Cuando una palabra tenga sentido especializado en un perfil, se conserva la diferencia.
3. El glosario común debe crecer solo cuando la práctica revele ambigüedad material.
4. No se crea sinonimia artificial para lograr simetría estética.
5. Las definiciones permanecen candidatas hasta su contraste final con IT y AT.
