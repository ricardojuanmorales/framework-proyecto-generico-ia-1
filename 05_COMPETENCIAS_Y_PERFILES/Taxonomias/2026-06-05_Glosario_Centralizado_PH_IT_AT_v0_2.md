## 0. Propósito

Este glosario centralizado define el lenguaje común mínimo del ecosistema PH-IT-AT-Caleidoscopio para la Fase 2.

La versión v0.1 usó como inventario semilla un glosario técnico de programación con términos como algoritmo, API, backend, base de datos, Git, JSON, testing, UI, UX, YAML y otros conceptos de desarrollo de software. La versión v0.2 añade el **núcleo conceptual-operativo mínimo** del Framework para que la base de conocimiento no dependa solo de vocabulario técnico externo.

---

## 1. Cambio principal de v0.2

```text
v0.1 = glosario semilla técnico y estructura inicial.
v0.2 = glosario semilla técnico + núcleo conceptual-operativo propio del Framework.
```

Esta versión no pretende cerrar todos los términos técnicos. Su prioridad es estabilizar el idioma mínimo de trabajo para:

```text
1. archivo canónico y rutas;
2. referencias lógicas y deuda;
3. transferencia simétrica;
4. base común y base específica;
5. documentación activa;
6. niveles N1-N4;
7. taxonomía;
8. seguridad longitudinal;
9. caleidoscopio;
10. gobernanza de crecimiento del glosario.
```

---
