# Modelo progresivo de construcción de Fase 2 desde evidencia v0.1

**Fecha:** 2026-09-22
**Estado:** candidato metodológico estabilizado en rama
**Origen empírico:** integración PH + AI StoryLab 1

## 1. Tesis

Fase 2 no debe construirse como catálogo exhaustivo anticipado ni como improvisación sin estructura.

Modelo:

```text
ESQUELETO COGNITIVO COMÚN MÍNIMO
+
CONTENIDO SUSTANTIVO VALIDADO POR USO
```

## 2. Ciclo

```text
práctica
→ necesidad real
→ semilla de conocimiento
→ invocación
→ evidencia de utilidad
→ refinamiento
→ consolidación
→ reutilización
→ posible generalización
```

## 3. Esqueleto mínimo

Debe permitir:

- nombrar;
- localizar;
- invocar;
- versionar;
- distinguir responsabilidad epistemológica;
- registrar evidencia de uso;
- transferir;
- reabrir;
- gobernar riesgo.

## 4. Regla de producción

Antes de crear una nueva Base, catálogo, protocolo o familia documental:

> ¿Qué capacidad o actuación necesita este objeto, dónde apareció esa necesidad y qué evidencia existe de uso o necesidad recurrente?

Si la respuesta todavía no está madura:

```text
bitácora / semilla
!= objeto canónico maduro
```

## 5. Método invocable

Los métodos se tratan como procedimientos reutilizables que orquestan capacidades existentes.

No se convierten automáticamente en:

- competencias;
- Unidades Nucleares;
- identidad de perfil;
- obligación transversal.

SDD es el primer caso empírico PH identificado bajo esta regla.

## 6. Complejización

Complejizar solo cuando aparezca al menos una condición fuerte:

- repetición real;
- volumen que excede navegación simple;
- riesgo que exige formalización;
- necesidad multiusuario;
- necesidad de seguimiento longitudinal;
- evidencia de reutilización;
- dependencia crítica;
- decisión de gobernanza.

## 7. Resultado esperado

Fase 2 crece por acumulación gobernada de conocimiento probado, sin perder lenguaje común ni arquitectura de referencia.
