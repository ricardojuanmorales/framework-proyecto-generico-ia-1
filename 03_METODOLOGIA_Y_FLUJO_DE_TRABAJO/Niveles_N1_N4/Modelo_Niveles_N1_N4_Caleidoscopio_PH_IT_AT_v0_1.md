## 1. Propósito

Este modelo define cómo interpretar los niveles N1-N4 en proyectos individuales y caleidoscópicos de la tríada PH-IT-AT.

Los niveles N1-N4 representan madurez operativa común. No representan jerarquía disciplinaria ni superioridad de un perfil sobre otro.

---

## 2. Decisión base

El nivel principal de un proyecto caleidoscópico se define por la complejidad del proyecto.

Para estudiar progreso y evolución se documentan tres capas:

```text
Nivel del usuario
Nivel del proyecto
Nivel del producto
```

La progresión de los perfiles activados debe sostener simetría. Esto significa que los perfiles no tienen que producir el mismo tipo de artefacto, pero sí deben operar con madurez equivalente dentro del nivel declarado.

---

## 3. Capas de nivelación

| Capa | Pregunta guía | Uso |
|---|---|---|
| Usuario | ¿Qué puede hacer la persona o equipo con autonomía? | Diagnóstico formativo y andamiaje |
| Proyecto | ¿Qué complejidad exige el problema común? | Define nivel principal del caleidoscopio |
| Producto | ¿Qué madurez evidencia el artefacto producido? | Evalúa resultados y transferencia |

---

## 4. Niveles comunes

| Nivel | Madurez operativa | Rasgos comunes |
|---|---|---|
| N1 | Exploración guiada | Comprensión inicial, acompañamiento paso a paso, productos simples |
| N2 | Producción asistida | Uso de plantillas, guías, prompts y documentación funcional |
| N3 | Integración avanzada | Herramientas compuestas, automatización parcial, evaluación y trazabilidad |
| N4 | Ecosistema gobernado | Agentes, automatización robusta, gobernanza, sostenibilidad y transferencia compleja |

---

## 5. Simetría por perfil

| Nivel | PH | IT | AT |
|---|---|---|---|
| N1 | Guía técnica básica, prompt simple, recurso funcional inicial | Pregunta de observación, registro inicial, criterio simple | Sugerencia de experiencia, lenguaje o accesibilidad básica |
| N2 | Protocolo, plantilla o flujo asistido | Instrumento inicial, rúbrica o matriz básica | Narrativa, interfaz o mediación inicial |
| N3 | Herramienta compuesta, automatización parcial, documentación evaluable | Diseño metodológico, evidencia, análisis y evaluación | Prototipo de experiencia, visualización, mediación o análisis sensible |
| N4 | Ecosistema agéntico gobernado, operación y mantenimiento | Investigación robusta, validación, síntesis y publicación | Sistema de mediación transdisciplinaria, experiencia compleja y curaduría cultural |

---

## 6. Reglas de progresión

```text
1. El nivel principal del caleidoscopio lo define la complejidad del proyecto.
2. El nivel del usuario se documenta para adaptar el andamiaje.
3. El nivel del producto se documenta para evaluar madurez real.
4. Los perfiles activados deben progresar de forma simétrica.
5. El lente latente debe calibrarse al nivel del proyecto.
6. Ningún proyecto sube de nivel sin evidencia documental.
7. Ningún producto se considera maduro sin seguridad, privacidad, datos o justificación de no aplicación.
```
